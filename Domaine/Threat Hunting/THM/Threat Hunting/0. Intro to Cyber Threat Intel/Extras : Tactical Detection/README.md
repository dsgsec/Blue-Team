# Introduction

Vous êtes embauché comme ingénieur de sécurité et vous voulez faire bonne impression. Vous avez remarqué qu’il existe un ensemble de règles par défaut disponible et qu’il a déjà été activé. Le L'équipe semble fonctionner, mais pas aussi efficacement que vous pouvez vous y attendre - alors il se lève sur vous; les règles par défaut ne le couperont tout simplement pas.

Ce scénario n'est pas rare - en fait, un écueil commun de SOC modernes aujourd'hui s'appuie trop sur les règles et les paramètres par défaut des produits qu'ils déploient, leur laissant des alertes de sécurité qui n'ajoutent pas vraiment de la valeur à leur posture de sécurité.
