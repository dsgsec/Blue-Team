Cette salle abordera les concepts du renseignement sur les menaces et divers outils open source utiles. Les objectifs d'apprentissage sont les suivants :
-   Comprendre les bases du renseignement sur les menaces et ses classifications.
-   Utilisation d'UrlScan.io pour rechercher les URL malveillantes.
-   Utilisation d'Abuse.ch pour suivre les indicateurs de logiciels malveillants et de réseaux de zombies.
-   Enquêterhameçonnagecourriels utilisant PhishTool
-   Utilisation de la plateforme Talos Intelligence de Cisco pour la collecte de renseignements.
